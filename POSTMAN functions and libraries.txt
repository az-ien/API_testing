---------------------------------------------------------chaining exmaple---------------------------------------------------------------------------------------

In tools like Postman, you can save the id from the POST step into an environment variable:

// In POST request Tests tab
pm.environment.set("itemId", pm.response.json().id);

Then use it in the GET and DELETE URLs:

GET https://example.com/api/items/{{itemId}}
DELETE https://example.com/api/items/{{itemId}}

This automates chaining across requests.

---------------------------------------------------------ASSERTIONS----------------------------------------------------------------------------------------------

pm.test("Status code is 200", () => {
    pm.response.to.have.status(200);
});

pm.test("Status code is 200 or 201", () => {
    pm.expect(pm.response.code).to.be.oneOf([200, 201]);
});

pm.test("Status text is Created (201)", () => {
    pm.response.to.have.status("Created");
});
