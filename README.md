# API Testing

API testing repository focused on REST API validation using Postman and automation frameworks.

## Description

For API Git Actions testing with comprehensive Postman collections and related documentation.

## Contents

### Postman Collections
- **My API.postman_collection.json** - Basic API collection
- **My API Chaining.postman_collection.json** - API chaining workflows
- **My API Chaining variables.postman_collection.json** - Variables for API chaining
- **My API variables.postman_collection.json** - Global and environment variables
- **My API workflow.postman_collection.json** - Automated workflow tests

### Documentation
- **Baiscs** - API basics and fundamentals
- **POSTMAN functions and libraries.txt** - Postman scripting reference
- **students.json** - Sample test data

### Project Structure
- **.postman/** - Postman configuration directory
- **postman/** - Additional Postman resources

## Technology Stack

- Postman (API testing)
- REST APIs
- JSON (data format)

## Usage

1. Import collections into Postman
2. Configure environment variables
3. Execute test workflows
4. Review results and logs
